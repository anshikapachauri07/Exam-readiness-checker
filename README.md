# Exam Readiness Checker

A beginner-friendly Python project that evaluates a student's exam preparation by analyzing syllabus completion, practice accuracy, mock test performance, and revision progress.

## Project Overview

The **Exam Readiness Checker** is a Python-based program designed to give students a simple overview of their exam preparation.

The program collects information about:

* Syllabus completion
* Practice questions attempted and answered correctly
* Mock test performance
* Revision sessions completed

It then calculates individual performance percentages and generates an **Overall Readiness Score**.

The program also identifies areas that may need improvement.

## Objectives

The main objectives of this project are:

1. To analyze a student's syllabus completion.
2. To calculate practice accuracy.
3. To evaluate mock test performance.
4. To measure revision progress.
5. To calculate an overall exam readiness score.
6. To identify areas needing improvement.
7. To demonstrate basic Python programming and problem-solving concepts.

## Performance Classification

The program classifies individual performance using the following ranges:

| Percentage    | Status            |
| ------------- | ----------------- |
| 80% and above | Excellent         |
| 60% – 79.99%  | Good              |
| 40% – 59.99%  | Moderate          |
| Below 40%     | Needs Improvement |

For the overall readiness score:

| Score         | Overall Status    |
| ------------- | ----------------- |
| 80% and above | Excellent         |
| 60% – 79.99%  | Good              |
| Below 60%     | Needs Improvement |

## Calculations

### Syllabus Completion

```text
Syllabus Completion =
(Completed Topics / Total Topics) × 100
```

### Practice Accuracy

```text
Practice Accuracy =
(Correct Answers / Attempted Questions) × 100
```

### Revision Completion

```text
Revision Completion =
(Completed Revision Sessions / Planned Revision Sessions) × 100
```

### Overall Readiness Score

```text
Overall Score =
(Syllabus % + Practice % + Mock Test % + Revision %) / 4
```
